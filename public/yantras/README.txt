HOW TO UPLOAD PRODUCT PHOTOS
=============================
Drop a photo into this folder named EXACTLY like the product's slug below,
using .jpg, .jpeg, .png, or .webp. As soon as you commit + push (or redeploy
on Vercel), the site will automatically show your photo instead of the
placeholder Om symbol — no code changes needed.

Example: premium-shaligram-kuber-yantra.jpg
