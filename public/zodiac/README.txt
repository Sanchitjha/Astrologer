HOW TO UPLOAD ZODIAC SIGN PHOTOS
==================================
Drop a photo into this folder named EXACTLY like the sign's slug below,
using .jpg, .jpeg, .png, or .webp. As soon as you commit + push (or redeploy
on Vercel), the site will automatically show your photo instead of the
current icon SVG — no code changes needed.

Example: aries.jpg
