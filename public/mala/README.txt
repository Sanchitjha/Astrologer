HOW TO UPLOAD MALA PHOTOS
============================
Drop a photo into this folder named EXACTLY like the slug below, using
.jpg, .jpeg, .png, or .webp. As soon as you commit + push (or redeploy on
Vercel), the site will automatically show your photo instead of the
placeholder 📿 icon — no code changes needed.

Example: rudraksha-mala.jpg
