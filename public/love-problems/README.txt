HOW TO UPLOAD PHOTOS FOR THESE 3 CARDS
=========================================
Drop a photo into this folder named EXACTLY like the filename below, using
.jpg, .jpeg, .png, or .webp. As soon as you commit + push (or redeploy on
Vercel), the site will automatically show your photo instead of the
placeholder emoji icon — no code changes needed.

Example: love-problem-solution.jpg

FULL LIST OF 3 FILENAMES (use any one extension per file):
---------------------------------------------------------------------
love-problem-solution
horoscope-matching
love-marriage-specialist
